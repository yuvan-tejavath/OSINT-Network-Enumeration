# Nmap Host and Service Detection

## Objective

Summarize the Nmap scanning exercise documented in the supplied training material.

## Tool

- Nmap, run from a Kali Linux environment.

## What the exercise covers

The supplied Nmap-related documentation is part of a set of network-enumeration exercises. It includes host discovery and service/port identification work. The separate NSE record provides the specific scan output and is documented in [Nmap NSE Scripts](Nmap-NSE-Scripts.md).

## Reporting checklist

For each authorized scan, record:

- Approved target and scope
- Date and time of the scan
- Nmap version
- Scan options used
- Host state
- Open ports and detected services
- Any filtered or non-responsive ports
- Limitations and follow-up validation

## Evidence and limitations

The supplied `Nmap Detect.pdf` contains a Snort alert screenshot rather than a readable Nmap command transcript. The alert observations are therefore documented separately in [Snort Alert Observations](Snort-Alert-Observations.md). No Nmap commands or scan results have been fabricated for this page.
